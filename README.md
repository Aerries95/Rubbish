# Rubbish
如名，Rubbish编程语言
Rubbish 语言 使用文档

概览
- 这是一个基于 `compiler.py` 的轻量脚本语言（解释器运行）。
- 运行：使用项目根目录下的 `rubbish` 命令（Windows 下为 `rubbish.bat`）或直接用 Python 运行：

  ```powershell
  .\rubbish your_file.rb
  # 或
  python compiler.py your_file.rb
  ```

词法与注释
- 单行注释：以 `//` 开始。
- 字符串：使用双引号，示例："hello"。
- 支持整数、浮点数字面量。

基本类型
- 支持类型：`int`、`float`、`bool`、`str`。

变量与声明
- 变量声明必须带类型并用 `=` 初始化：

  ```
  int x = 1
  str s = "hi"
  ```

数组（1 起始索引）
- 声明固定维度数组：`int a[3] = {1,2,3}`。
- 多维数组支持：`int m[2][2] = {{1,2},{3,4}}`。
- 下标从 1 开始：`a[1]` 表示第一个元素（不是 0）。
- 支持数组元素赋值：`a[1] = 5` 或 `m[1][2] = 7`。
- 支持嵌套初始化器 `{...}`。

函数定义与调用
- 语法：`def [返回类型] name([参数列表]) { ... }`。
  - 返回类型可选，例如 `def int add(int x, int y){ ... }`。
  - 参数以 `类型 名称` 形式给出，逗号分隔。
- 返回：使用 `return(expr)` 或 `return expr`。
- 调用：`add(2,3)`。函数可在表达式或语句位置调用；作为语句调用时会忽略返回值。
- 示例：
  ```
  def int add(int x, int y){
      return(x + y)
  }

  def main(){
      print(add(2,3))
  }
  ```
- 当前实现：参数在调用时绑定为局部变量；类型标注目前不会强制运行时检查（可作为文档/默认值用途）。

控制流
- `if` / `elif` / `else`：
  ```
  if (x < 10) { ... } elif (x == 10) { ... } else { ... }
  ```
- `for`：特殊计数型 `for (count, var)`，从 1 到 `count`（含）：
  ```
  for (5, i) { print(i) }  // 打印 1..5
  ```
- `while`：标准 `while (cond) { ... }`。
- `break` 与 `continue` 在循环中使用。

表达式与运算符（当前支持）
- 算术：`+`, `-`。
- 比较：`<`, `>`, `==`。
- 注：目前不支持 `*`, `/`, 布尔运算符 `&&`/`||`/`!`（可扩展）。

内置函数
- `print(expr)`：打印表达式，数组会以 `{...}` 格式显示。
- `len(array)`：返回数组长度（对一维数组适用）；`len` 必须接收数组。
- `input()` 或 `input(prompt)`：读取一行输入；如果是纯整数文本会自动转成 `int`，否则返回 `str`。
- `random(a,b)`：返回一个包含端点的整数随机数，a 和 b 必须为整数，返回值在 [a, b] 区间（含）内。

数组成员方法
- `a.max` 或 `a.max()`：返回数组中的最大值（支持多维数组，会展平后取最大）。
- `a.min` 或 `a.min()`：返回数组中的最小值（支持多维数组，会展平后取最小）。
- 当前 `max/min` 支持数值数组（`int` / `float`）。

返回与作用域
- 函数内部 `return` 会立即结束函数并返回值。
- 函数执行时使用独立局部环境（不会污染调用方环境）。

LLVM IR 生成（实验性）
- `compiler.py` 包含一个简单的文本 LLVM IR 生成器 `generate_llvm_ir`，但实现不完整：
  - 仅对字符串常量打印生成 IR，其它（如数组、复杂函数签名）会被跳过以避免崩溃。
  - 由于在 Windows 上 `llvmlite` 难以构建，IR 为文本生成以保持可用性。

示例文件
- 项目中已有示例：`param_test.rb`（函数参数示例）、`return_test.rb`（返回示例）、`array_test.rb`（数组示例）。

当前已知限制
- 未实现乘除和布尔短路运算符。
- `input()` 尚未实现为阻塞的运行时输入。
- 类型注解目前不会在运行时严格检查。
- LLVM IR 生成器对数组和函数体支持有限。

快速上手
1. 编辑示例或创建新的 `.rb` 文件（语言拓展为演示用途）。
2. 在项目根目录运行：

```powershell
.\rubbish your_program.rb
```
